Inglés INPV311 — Actividades accesibles

Selecciona una unidad para comenzar. Cada unidad son ejercicios con corrección automática.

  • File 1A — Verb to be, saludos, días y números
  • File 1B — Verb to be (pregunta/negación), nacionalidades, números 21-100
  • File 1C — Adjetivos posesivos
  • Ver mi progreso y nota estimada

Cómo funciona cada unidad

  • Cada ejercicio tiene un botón "Verificar" que revisa tus respuestas. Si hay alguna incorrecta, el cursor salta automáticamente a la primera que debas revisar.
  • El botón "Ir al siguiente error" te lleva directo a la próxima respuesta incorrecta, sin tener que recorrer todo el formulario para encontrarla.
  • Al terminar, "Finalizar unidad y ver resumen" te muestra tu puntaje y te deja copiarlo en texto plano.
  • El link "Volver al menú de unidades" está arriba y al final de cada página.

Navegación recomendada con NVDA

  • Say All (Insert + flecha abajo): para escuchar una oración o sección completa de corrido, sin cortes.
  • Tab / Shift + Tab: para saltar directo entre espacios en blanco, hacia adelante o hacia atrás.
  • Insert + Espacio: para salir de un espacio en blanco y volver a poder leer con flechas, si el cursor queda "atrapado" ahí.
En la configuración de NVDA (Preferencias → Configuración → Modo Exploración), conviene dejar desmarcada la opción "Modo foco automático para el movimiento del cursor" — si está marcada, la lectura con flechas se corta en cada negrita o punto de lista.
