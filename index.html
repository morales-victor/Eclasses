Inglés INPV311: actividades accesibles

Selecciona una unidad para comenzar. Cada unidad son ejercicios con corrección automática.

  • File 1A: verb to be, saludos, días y números
  • File 1B: verb to be en preguntas, nacionalidades y números del 21 al 100
  • File 1C: adjetivos posesivos
  • File 2A: a y an, y plurales
  • File 2B: adjetivos, colores y modificadores
  • File 3A: presente simple y rutina diaria
  • File 3B: preguntas en presente simple y trabajos
  • File 3C: orden de las palabras en preguntas
  • Ver mi progreso y nota estimada

Cómo funciona cada unidad

  • Cada ejercicio parte con un cuadro "Recuerda" y un ejemplo resuelto.
  • Los ítems están agrupados en partes, y cada parte tiene su propio subtítulo y su propio ejemplo. Puedes saltar de una parte a otra con la tecla 4, que lleva al siguiente subtítulo.
  • El botón "Verificar" revisa tus respuestas. Si hay alguna incorrecta, el cursor salta automáticamente a la primera que debas revisar.
  • El botón "Pedir ayuda a la IA" copia una pregunta lista para Claude, sobre el primer espacio vacío del ejercicio. Si todos están llenos, la pregunta es sobre el primero incorrecto. Si te quedas pegado en un ítem, déjalo vacío y presiona el botón.
  • Justo después de ese botón está el enlace "Abrir Claude en una pestaña nueva". Ahí pega la pregunta con Control más V y presiona Enter. Para volver a la guía, cierra esa pestaña con Control más W.
  • El botón "Ir al siguiente error" te lleva directo a la próxima respuesta incorrecta, sin tener que recorrer todo el formulario.
  • Al terminar, "Finalizar unidad y ver resumen" te muestra tu puntaje y te deja copiarlo en texto plano.
  • El enlace "Volver al menú de unidades" está arriba y al final de cada página.

Navegación recomendada con NVDA

  • Say All, con Insert más flecha abajo: para escuchar una oración o sección completa de corrido, sin cortes.
  • Tab, o Shift más Tab: para saltar directo entre espacios en blanco, hacia adelante o hacia atrás.
  • Insert más Espacio: para salir de un espacio en blanco y volver a poder leer con flechas, si el cursor queda atrapado ahí.
En la configuración de NVDA, en Preferencias, Configuración, Modo Exploración, conviene dejar desmarcada la opción "Modo foco automático para el movimiento del cursor". Si está marcada, la lectura con flechas se corta en cada negrita o punto de lista.
